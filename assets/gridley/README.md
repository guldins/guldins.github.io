# Gridley Mascot Asset System

Gridley now exists as a **character asset separate from the original campaign poster**. The website should use the standalone character files for identity and storytelling, while the complete poster remains available as a distinct reference and campaign artifact.

| Asset | Intended use | Source relationship |
| --- | --- | --- |
| `gridley-headshot.webp` | Header mark, hanging sign, footer mark, avatar, and compact circular placements | Framed from the newly rendered standalone character; not cropped from the poster |
| `gridley-standalone-seated.webp` | Main website mascot section, print compositions, social graphics, and general brand use | Newly rendered full-body Gridley with transparent background |
| `gridley-animation-neutral.webp` | Motion studies, storyboards, and the starting reference for a future rig | Newly rendered neutral standing pose with four separated legs and a clean silhouette |
| `gridley-full-mascot-poster.webp` | Complete poster, campaign storytelling, reference, and stakeholder review | Preserved full poster artwork |
| `masters/` | High-resolution transparent PNG source assets | Production masters for future derivative exports |

## Character identity anchors

Every future Gridley illustration should preserve the same warm brown eyes, floppy ears, friendly white puppy proportions, forest-green patch around the eye on the viewer’s right, rounded red/green/gold spots, polished gold collar, and readable `OTG` tag. The rendering style should remain a warm, polished 3D storybook illustration rather than becoming photorealistic or flat clip art.

## Animation path

The neutral standing pose is **animation-ready as a character reference, not yet a production rig**. The minimum effective next phase is to approve this identity, create a five-expression sheet and three-quarter side view, then separate the head, ears, eyes, mouth, legs, and tail into layered rig components. Motion should begin with a subtle idle loop—blink, ear bounce, breathing, and tail wag—before investing in walk cycles or talking animation.
